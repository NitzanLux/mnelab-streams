# Test data

`multirate_mock.xdf` is a deterministic XDF integration fixture containing numeric
streams at 100 Hz, nominal 250 Hz, and 20 Hz plus an irregular marker stream. It
includes known stream boundaries, a measured/nominal rate mismatch, one acquisition
gap, and explicit NaN samples.

Its ground truth is defined in `generate_multirate_xdf.py`:

- EEG has 201 continuous samples at exactly 100 Hz from 0.0 through 2.0 seconds.
- EMG declares 250 Hz but has authoritative version-2 per-sample timestamps at
  exactly 247 Hz. Samples from 0.8 through 1.2 seconds are absent, and ten values
  are explicitly NaN.
- Camera frame indices run from 0 through 32 at 20 Hz, starting at 0.2 seconds.
- Marker values are `start` at 0.25 seconds and `stop` at 1.25 seconds.

The EMG pause is intentionally shorter than PyXDF's default break threshold at the
declared rate. This makes the fixture a regression test for metadata-driven loading:
MNELAB must preserve the explicit 247 Hz timing and the pause without imposing
250 Hz or applying PyXDF de-jittering. Separate deterministic tests construct legacy
repeated-stamp and scalar-chunk streams and verify their measured-rate recovery.

Regenerate it from the repository root with:

```powershell
python tests/data/generate_multirate_xdf.py
```

`tests/test_multirate_xdf_fixture.py` verifies that regeneration is byte-identical
and checks the fixture's complete native-load, activation-map, and resampling path.
The committed fixture is 18,616 bytes with SHA-256
`019781AC2A56EF751EAB79645D89CDAC5A97ACCA00B3A7DB5A084B8DD1392676`.

The NPZ files in this directory contain reference data for ICLabel integration tests
and are generated by `generate_test_data.py`.
